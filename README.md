# Library Management System

## Description
A simple Library Management System implemented in Java using Object-Oriented Programming (OOP).
The project allows adding books to a library and displaying all stored books.

## Language & Concepts
- Java
- Object-Oriented Programming (OOP)
- Arrays

## Classes
- **Book**: Represents a book with a title, author, and publication year.
- **Library**: Stores and manages books using an array.
- **MainLibrary**: Runs the application and tests the system.

## Key Features
- Add books to the library
- Display all available books
- Handle library capacity limits

## Key Methods
- `Book(String title, String author, int year)`
- `addBook(Book book)`
- `displayBooks()`

## Tools Used
- Visual Studio Code
